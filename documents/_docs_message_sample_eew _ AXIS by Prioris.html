注意 : 本電文の配信は実験的なものです。商用利用の他、一般公開目的の利用もお控えください。

この配信は、地震発生時の情報処理、表現方法、発信方法の実験と検討を目的として公開しています。
実験的な配信のため、予告なく電文フォーマットを変更することがあります。

配信する電文の遅延は考慮されておらず、確実な電文の配信も保証していません。
本電文を一般向け(Twitterなど)に公開する事はお控えください。

上記の実験目的を逸脱した二次配信、再配信、一般公開などを発見した場合は、予告なくアカウントの停止及び実験的公開の停止を行う可能性があります。

Message

key type description
Title String 緊急地震速報（予報） または 緊急地震速報（警報）
OriginDateTime String 地震発生日時
ReportDateTime String 電文発表日時
EventID String 地震ID
Serial Integer この電文が何報目か
Hypocenter.Code Integer 震源地コード
Hypocenter.Name String 震源地名
Hypocenter.Coordinate Array<Float> 経度, 緯度
Hypocenter.Depth String 震源の深さ
Hypocenter.Description String 文章整形済み震源情報
Intensity String 推定される最大震度 (1,2,3,4,5-,5+,6-,6+,7,不明)
Magnitude String 推定されるマグニチュード
Flag.is_final Boolean この電文が最終報か
Flag.is_cancel Boolean この電文がキャンセル報か
Flag.is_training Boolean この電文は訓練か
Forecast Array 揺れが予想される地域 (最大震度4以上の場合) / 無い場合は空の配列
Text String 補足事項

Forecast

key type description
Code Integer 地域コード
Name String 地域名
Intensity.From String 最大予測震度の下限 (0,1,2,3,4,5-,5+,6-,6+,7,不明)
Intensity.To String 最大予測震度の上限 (0,1,2,3,4,5-,5+,6-,6+,7,over,不明)
Intensity.Description String 文章整形済み最大震度 (日本語)
